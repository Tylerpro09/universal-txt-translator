1. Inicio rápido

Abre la aplicación, selecciona tu TXT en el área de carga o pega su contenido en el editor integrado. Pulsa Validar TXT y Activar idioma. A continuación, introduce el texto y elige el sentido de traducción.

No existen idiomas precargados. Para producir una traducción, el archivo debe incluir equivalencias explícitas.

2. Estructura mínima de un idioma

Usa las secciones [ALFABETO] para caracteres o [DICCIONARIO] para palabras y frases. Se pueden combinar.

ORIGEN: Español
IDIOMA: Otro idioma

[ALFABETO]
a = ★
b = ☆

[DICCIONARIO]
hola = saludo
buenos días = saludo matinal

El ejemplo es demostrativo y no se carga automáticamente. Guarda tus definiciones como .txt UTF-8.

3. Traducción y detección

Puedes traducir de origen a destino o a la inversa. La opción automática examina las coincidencias disponibles para estimar el sentido. Si ambos sistemas utilizan caracteres similares, el resultado puede ser ambiguo y es mejor elegir la dirección manualmente.

El motor prioriza coincidencias completas de palabras o frases; después aplica el alfabeto a los fragmentos restantes. Los trozos desconocidos se conservan sin inventar una traducción.

5. CLI y API de desarrollo

Puedes utilizar la biblioteca JavaScript motor_idiomas.js en tu propia aplicación o traducir desde una consola con Node.js 22+.

npm test
node cli.js --help
node cli.js -p mi_idioma.txt -t "hola" -d encode

6. Límites y privacidad

Los TXT se procesan dentro de tu navegador. No se envían a un traductor remoto. El almacenamiento opcional de perfiles utiliza localStorage; no se guardan automáticamente los mensajes que escribas. Los recursos públicos del sitio sí se sirven desde GitHub Pages.

Máximo: 2 MB por TXT, 5000 equivalencias y 160 caracteres por lado. La detección no es infalible. No se interpretan gramáticas ni se descifran idiomas desconocidos mediante IA.

Un alfabeto secreto no es cifrado seguro. El motor no protege conversaciones confidenciales mediante criptografía.

Uso sin Wi-Fi

Abre la aplicación una vez con Internet y pulsa Guardar para usar sin Wi-Fi. Cuando indique que todos sus recursos están almacenados, podrás volver a abrirla en este mismo navegador aunque desactives el Wi-Fi y los datos móviles.

Para llevarte el traductor a otro equipo, descarga y descomprime la versión portátil del repositorio y abre index.html. Necesitas conservar tus archivos TXT de idiomas.

Sin conexión siguen funcionando la traducción local, el editor, los TXT guardados en el dispositivo y la documentación web básica. Los enlaces a GitHub y las actualizaciones sí necesitan Internet.
